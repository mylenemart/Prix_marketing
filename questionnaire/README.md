# Questionnaire prix Parc Astérix / Disneyland Paris

Questionnaire en ligne de l'étude de prix (Master 1) : test A/B d'intention d'achat à 55 € ou 65 € tiré au hasard, puis méthode Van Westendorp pour les deux parcs.

- **Mise en ligne** : Settings → Pages → Deploy from a branch → `main` / racine.
- **Collecte des réponses** : suivre les étapes en tête de `apps-script.gs`, puis coller l'URL dans `ENDPOINT` (index.html). Tant que `ENDPOINT` est vide, le site est en mode test et n'envoie rien.
